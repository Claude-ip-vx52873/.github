<p>预算紧的时候买住宅 IP 池，最容易犯的错是「先买便宜的，出问题再换」。换一次服务商的成本远高于省下的差价：重验归属、重建环境、账号重新适应新出口，一轮下来两三天没了。所以这份清单的目标不是买到最便宜的，而是一次买对、少折腾。六个决策按顺序排，前三个决定池子能不能用，后三个决定能不能长期用。每项给默认选项和需要改判的条件，照着确认一遍，比反复比价省时间。</p>
<h2>一、六个决策排个序</h2>
<p>顺序有讲究。先确认地址段类型，再确认供应商是自营还是转售，再看池子规模与复用度，最后才谈预算和长期合作。反过来从预算开始，往往会在第一项上妥协，后面全是补救。</p>
<h3>每项给一个默认选项</h3>
<p>默认选项是「不用想太多就这样选」的答案。只有满足改判条件时才动，这样决策成本最低，也不容易被销售话术带偏。六项里最不该改判的是地址段类型，最可以灵活的是池子规模。</p>
<h3>改判条件要写得具体</h3>
<p>比如「预算不足」不是改判条件，「预算不足且只跑两周验证」才是。条件写得越具体，越不容易在压力下做出错的决定。下面每一项都尽量给到可验证的条件，而不是感觉。</p>

<h2>二、决策一：地址段是家宽还是机房</h2>
<p>这一项决定池子的性质。住宅池之所以叫住宅池，是因为地址来自家庭宽带接入，而不是数据中心分配出来的段。两者在归属库里的差别一眼可见。</p>
<h3>三个判断入口</h3>
<p>入口一，ASN 指向谁。指向 Comcast、Verizon、AT&amp;T 这类本地宽带运营商的，是家宽；指向 AWS、DigitalOcean、Hetzner 这类云厂商的，是机房。入口二，接入类型字段。ipinfo 一类服务会标注 ISP 与 hosting，标 hosting 的直接排除。入口三，反向解析。家宽地址常常没有反向解析，或者解析到运营商的动态域名，机房地址通常有规整的反解。</p>
<h3>为什么会有人拿机房段冒充</h3>
<p>因为机房段便宜、稳定、好维护。但它在归属层面就是「不是家宽」，用在注册、订阅扣费这类动作上，差异会直接体现在提示频率上。判断方法不复杂，动手查一遍就清楚，不必听描述。</p>
<h2>三、决策二：自营还是转售，看三个信号</h2>
<p>「长期自营线路」这句话，只有能被验证才成立。转售商也能说出同样的话，区别在于出问题时他能给你什么。</p>
<h3>信号一：能不能看到线路变更记录</h3>
<p>自营能提供每条线近三十天的出口变更、路由抖动、可用率数据。转售通常只能给一个当前 IP 和到期时间。要一份最近七天的变更记录，能立刻给出来的是自营，说要问上游的多半是转售。</p>
<h3>信号二：换线要不要额外收费</h3>
<p>自营换线通常是内部调配，成本低；转售换线要向上一层申请，往往收费或拖延。合作前问清「一年内可以免费换几次」，答案能反映层级。</p>
<h3>信号三：工单响应的人是谁</h3>
<p>技术问题能不能直接对话到懂线路的人，是自营与转售最实在的区别。转售的客服只能转达，来回两轮就过去一天。这一条试用期就能验证：提一个稍微技术一点的问题，看回复质量。</p>

<h2>四、决策三：池子规模与复用度怎么读</h2>
<p>池子大不等于好用。决定体验的是「你拿到的那条线最近被多少人用过」，而不是池子里一共多少条。</p>
<h3>规模看容量，复用度看同段账号数</h3>
<p>规模问的是目标地区的可用容量，而不是总池子规模。一个号称百万级的池子，在你需要的那个城市可能只有几十条可用。要按地区问，不要按总量问。复用度则看同一条 /24 段里我方账号数，控制在 2 个以内，超过这个数，一个号出问题其他号会被一起牵连。这一项自己就能统计，把台账按段分组看一遍即可。</p>
<h3>池子会不会越用越差</h3>
<p>会。同一批地址被反复分配之后，干净度会下降。判断办法是每季度抽查一次：随机取十条线，查是否出现在公开代理清单里。出现比例上升，说明这个池子在退化，该考虑补充新段。</p>
<h2>五、预算分配与长期合作的判断</h2>
<p>钱不多的时候，分配顺序比总额更重要。同样的预算，分配对了能跑，分配错了天天救火。</p>
<h3>预算紧的分配顺序</h3>
<p>第一优先是地址段类型，机房段再便宜也不选；第二优先是独享，宁可少几个号也要保证一条线一个号；第三优先是地区准确，指定城市能兑现；最后才考虑带宽和增值服务。带宽在这个场景里几乎不是瓶颈，几十 K 每秒就够跑注册和对话。</p>
<h3>什么情况算值得长期用</h3>
<p>三个指标：连续三个月可用率在 99% 以上、出口变更多于每月一次的情况不超过一次、技术问题能在半天内得到有效回复。三项都达标，可以谈长约；有一项不达标，先按月续，观察一个季度再定。</p>
<h3>换服务商的成本要提前算</h3>
<p>换一次要重验归属、重建环境、账号重新适应，按经验是两到三个人天加上一批线路的沉没成本。所以「便宜三成但每季度要换一次」的方案，一年下来比稳定方案更贵。</p>

<h2>六、常见问答</h2>
<h3>预算只有几百块，能买住宅池吗？</h3>
<p>答：能，但要缩小规模。几百块建议只做一条高质量独享线加少量备用，不要摊成十条低质共享线。质量优先于数量，这个场景里尤其明显。</p>
<h3>怎么快速确认一条线是不是家宽？</h3>
<p>答：查 ASN 指向的运营商，再看接入类型是否标注 hosting。两步三十秒能出结果。指向云厂商的一律不是家宽，不必再问。</p>
<h3>池子里的地址会被别人用过吗？</h3>
<p>答：会，住宅池本质上是复用资源。能做的是控制自己这边的同段账号数，并在入库时抽查是否出现在公开代理清单。完全没用过的新段很少，也不必强求。</p>
<h3>长期合作要不要签年框？</h3>
<p>答：先跑满三个月再谈。年框通常能便宜一到两成，但一旦线路质量下滑，退出成本很高。谈年框时把可用率与换线次数写进条款。</p>
